# Calculadora de Honorários Advocatícios (versão completa)

## Funcionalidades
- Modelos: Tabela OAB, Percentual, Fixo, Hora técnica, Êxito, Misto
- Custo real da hora do escritório
- Comparação de até 3 cenários
- Sucumbência (art. 85 CPC)
- Correção 2016→2026 e fator de complexidade
- Exportação PDF e TXT da proposta
- Cláusulas contratuais modelo
- Busca de serviços + categorias expandidas

## Como executar
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Base
OAB/SP 2016 + referências de mercado 2025/2026. Valores orientativos.
